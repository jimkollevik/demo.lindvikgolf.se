# Lindviks Golfklubb

En enkel, responsiv PoC för en fiktiv svensk golfklubb. Byggd i vanlig HTML, CSS och JavaScript utan ramverk.

## Kom igång

Öppna `index.html` direkt i en webbläsare. Bilder och typsnitt laddas från externa tjänster när du har internetanslutning.

## GitHub Pages

Repot är förberett för GitHub Pages via GitHub Actions. När repot har skapats, välj **Settings → Pages → Source: GitHub Actions**. Workflowen publicerar webbplatsen från repo-roten vid varje push till `main`.

## Innehåll

- Mobilanpassad startsida med klassisk klubbkänsla
- Fiktiva greenfeepriser, öppettider, baneläge och klubbnyhet
- Frågor och svar
- Markerad framtida integrationspunkt för Caddie AI (agenten är inte implementerad)

Priser, status, nyhet och kontaktuppgifter är fiktiva PoC-exempel. Fotografi laddas från Pexels.
